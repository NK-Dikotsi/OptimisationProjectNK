# TUM racetrack data (Spielberg / Red Bull Ring)

Source: TUMFTM racetrack-database, https://github.com/TUMFTM/racetrack-database
Licence: GNU LGPL v3 (see LICENSE in this folder).

- `Spielberg.csv`: centreline `x_m, y_m` and track widths `w_tr_right_m, w_tr_left_m` (points about 5 m apart).
- `Spielberg_raceline.csv`: TUM's minimum-curvature race line `x_m, y_m`, computed with the
  method of Heilmeier et al. (2020). Used only as an external reference lap.

Cite in the paper: Heilmeier, A. et al. (2020), Minimum curvature trajectory planning and
control for an autonomous race car, Vehicle System Dynamics; and the database repository.
